# Ejercicio de control de ventas

Una tienda de tecnología desea llevar un control de ventas de sus productos. El día de hoy lanzó una promoción en la que sus tres productos principales serán los unicos que estarán disponibles. Quiere saber cual es el producto mas vendido (entre esos tres) solo con registrando las primeras 20 compras.

Desarrollar un algoritmo que pueda dar solución a la situación planteada.

Listado de productos:
- Xiaomi 18 Fold
- Iphone Duo
- Samsung Galaxy Fold 8
